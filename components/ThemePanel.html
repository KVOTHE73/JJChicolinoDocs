⚙️ Componente: ThemePanel.vue ​

🎨 Panel lateral de configuración visual para personalizar la interfaz de usuario de la aplicación.

✨ Funcionalidades principales ​

  • Cambiar el color principal de la aplicación mediante una paleta.
  • Activar o desactivar el modo oscuro.
  • Configurar visibilidad y estilo de:
    • Cabecera (fija, invertida, oculta)
    • Sidebar (fijo, invertido, rejilla, gradiente, oculto)
  • Guardar preferencias en localStorage para mantenerlas al recargar.
  • Cargar configuración previa en onMounted.

🧱 Estructura del componente ​

🔹 Props ​

Este componente no recibe props.

🔹 Emits ​

Este componente no emite eventos directamente, pero emite internamente mediante useEmitter.

🔹 Variables reactivas ​

VariableTipoDescripción
(internas del store)Se accede a todas desde useAppOptionStore y useAppVariableStore

🔧 Funciones principales ​

FunciónPropósito
toggleDark()Activa/desactiva modo oscuro
toggleSidebar()Oculta o muestra el sidebar
toggleHeader()Oculta o muestra la cabecera
setTheme()Aplica un nuevo color base a la app
setInitialConfig()Lee y aplica valores desde localStorage

🧩 Watchers y reactividad ​

  • Al cambiar cualquier opción visual, se actualiza el store y se guarda en localStorage.
  • Cambios como el color, modo oscuro, gradiente, etc. afectan directamente las clases del layout.

🛠️ Composables y stores utilizados ​

Composable / StorePropósito
useAppOptionStoreEstado visual global (modo oscuro, visibilidad, etc.)
useAppVariableStoreAplicación de variables CSS dinámicas por tema
useEmitterComunicación con otros componentes

🔄 Ciclo de vida ​

  • onMounted():
    • Carga configuración previa desde localStorage
    • Inicializa tooltips Bootstrap (data-bs-toggle="tooltip")

🎨 Temas disponibles ​

Incluye múltiples temas predefinidos:

  • Rojo, Rosa, Naranja, Amarillo, Verde, Azul, Púrpura, Negro
  • Aguamarina (por defecto)

🧠 Notas adicionales ​

  • Todas las preferencias se conservan incluso tras cerrar la app gracias a localStorage.
  • El panel está oculto por defecto y se muestra al hacer clic en el botón ⚙️ en el layout.
