En esta página:

🔐 Login ​

💡 Esta vista gestiona el acceso de usuarios a la aplicación.
Permite capturar las credenciales, autenticarlas y redirigir al usuario a su destino según su rol.

🔷 Funcionalidad ​

  • Captura usuario y contraseña mediante formulario con campos validados.
  • Permite marcar la opción "Recordarme" para conservar la sesión.
  • Verifica las credenciales contra el backend (actualmente con mock).
  • Redirige a /descargaERP si es planificador o a /principal si es operador.

🔷 Comportamiento UI ​

  • Se ocultan automáticamente el header y sidebar mientras se muestra la pantalla de login.
  • Se desactiva el scroll vertical (overflow: hidden) para ocupar el alto completo.
  • El fondo de login incluye una imagen decorativa (/assets/img/login-bg/login-bg-17.jpg).
  • El contenedor del formulario se centra verticalmente en pantalla.

🔷 Store y estado ​

  • Se accede a useAppOptionStore para modificar el estado visual de la vista.
  • Se usa useAuthStore para guardar el usuario y su rol tras login.
  • Se registra un beforeRouteLeave para restaurar la visibilidad del header y sidebar al abandonar esta vista.

🔷 Código relevante ​

ts
// Al montar
onMounted(() => {
  appOption.appSidebarHide = true;
  appOption.appHeaderHide = true;
  appOption.appContentClass = "p-0";
});

// Al salir
const beforeRouteLeave = (to, from, next) => {
  appOption.appSidebarHide = false;
  appOption.appHeaderHide = false;
  appOption.appContentClass = "";
  next();
};
