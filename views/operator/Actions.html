📘 Acciones ​

📦 Descripción general:
Vista de control de un ticket de acción en una máquina. Permite ver información del trabajo en curso, seleccionar una acción a realizar y gestionar el flujo mediante botones de control.

✨ Funcionalidades principales ​

  • 🔹 Visualizar el ticket activo con su progreso, artículo y máquina.
  • 🔹 Ver las secciones asignadas y el nombre del operador.
  • 🔹 Seleccionar una acción a realizar mediante radio buttons.
  • 🔹 Botones de control:
    • ▶️ Iniciar sistema
    • ⏸ Pausar sistema
    • 🔁 Refrescar ticket
    • 🧭 Volver / Mantener / Terminar ticket

🧱 Estructura visual y bloques del template ​

🔸 Secciones o bloques principales ​

🔧 Métodos y funciones principales ​

MétodoPropósito funcional
play()Activa el sistema (simulado)
pause()Pausa el sistema
logout()Cierra sesión y navega a /login
refreshTicket()Recarga datos del ticket actual
keep()Marca el ticket como mantenido y registra acción seleccionada
finish()Marca el ticket como finalizado y registra acción

🔹 Ciclo de vida ​

No se emiten eventos personalizados hacia el padre.

📡 Comunicación con el backend (API) ​

❗ Actualmente no hay integración real. Todas las acciones son simuladas con datos locales.

🧬 Interfaces y Tipado ​

⚠️ No hay interfaces explícitas definidas. Se recomienda definir una para el ticket y para la acción seleccionada cuando se integre con backend.

🛠️ Composables y stores utilizados ​

  • useAppOptionStore → Para detectar modo oscuro y gestionar opciones de layout global.
  • useLogger → Log de acciones (desarrollo).
