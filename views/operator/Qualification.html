📘 Cualificar ​

📦 Descripción general:
Vista encargada de gestionar la cualificación del ticket de acción en máquina. Permite seleccionar un motivo técnico entre varias opciones para completar el proceso.

✨ Funcionalidades principales ​

  • Visualización del ticket activo (máquina, hora, artículo, avance…).
  • Muestra opciones para cualificar el ticket (rotura, bobina, fin de sprint…).
  • Control de ejecución (Play, Pause).
  • Acción para volver a la pantalla anterior.
  • Adaptación completa a tema claro/oscuro.

🧱 Estructura visual y bloques del template ​

🔸 Secciones o bloques principales ​

SecciónDescripción
Barra de estadoInfo del operador y controles Play / Pause / Logout
Sección TicketInformación del ticket (máquina, hora, artículo, avance, etc.)
Sección CualificaciónBotones con acciones posibles para cualificar
Botón AtrásRegresa a la vista anterior usando router

🔸 Comportamiento condicional ​

  • v-if / v-show: para mostrar spinners o badges según estado
  • v-for: iteración de botones de opciones de cualificación
