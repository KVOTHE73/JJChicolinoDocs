📘 CP2025 – Plataforma de gestión interna ​

Aplicación interna para la gestión de usuarios planificadores y operadores

🔧 Proyecto en desarrollo – backend pendiente de implementación

🚀 Funcionalidades principales ​

  • 🧾 Gestión de vistas para flujo de trabajo de usuarios planificadores
  • 🧾 Gestión de vistas para flujo de trabajo de usuarios operadores
  • 📲 Versión responsive móvil y escritorio (Vue 3 + Typescript + Bootstrap)
  • 🔐 Login persistente con JWT
